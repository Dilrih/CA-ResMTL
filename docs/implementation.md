# Implementation

## Structure learning

The DOCD model learns directed relationships among encoded questionnaire variables and the outcome. The allowed-edge mask uses question order and blocks outgoing edges from the outcome. Structure training combines reconstruction, outcome likelihood, sparsity, and an acyclicity penalty. Optional bootstrap fitting estimates the stability of incoming outcome edges.

## Residual multitask prediction

The default `deep_resmlp` backbone embeds questionnaire responses, combines them with engineered interaction features, and processes them through residual blocks. The `CAResMTL` predictor combines score and probability heads through a learned fusion gate. Available depression and self-harm labels provide auxiliary tasks with uncertainty weighting.

The primary loss is asymmetric loss (ASL), with ranking and additional regularization terms controlled by the configuration. Group DRO uses domain membership; CORAL aligns domain representations. The alternative `causal_attention` and `ft_transformer` backbones use a dual-head predictor without auxiliary task heads.

Interaction selection, imputation medians, and normalization statistics are fitted using training rows and reused for validation and test transformations.

## Calibration and resumption

Calibration is fitted on validation predictions. Beta calibration uses

```text
sigmoid(a * log(p) - b * log(1 - p) + c), a >= 0, b >= 0
```

The identity parameters are `(a, b, c) = (1, 1, 0)`. The nonnegative coefficients preserve risk ordering.

Saved stage settings are loaded before explicit overrides are applied. Predictor resumption retains domain membership and auxiliary targets. Subsequent invocations write separate argument and manifest files while preserving the first run's metadata.

## Evaluation considerations

Category vocabularies, high-cardinality discretization boundaries, and depression-score quantiles are constructed from the combined dataset before the domain split. Interaction selection and structure mutual-information screening use training indices.

The optional stacker combines out-of-fold predictions from scikit-learn/tree classifiers with predictions from a neural model fitted on the training partition. Its neural features are not generated by retraining within each fold.

Intervention rankings are estimates from the fitted structure model. Question order and observational questionnaire data alone do not establish causal identification.

The synthetic example checks execution with reduced training and sampling budgets. Its settings and results are not a reproduction of a study experiment. Reproducing reported results requires the corresponding input data and complete experiment settings.
